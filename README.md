# Meta Publisher — Mr. One Iwan 2026

Repository utama proyek Meta Publisher Mr. One Iwan 2026.

## Tujuan

Membangun alur publishing konten yang sederhana untuk pengguna non-teknis, dengan fokus awal pada Facebook Page.

## Flow

1. **Discovery** — AI Research + Web/URL Research.
2. **Production** — analisis link, pembuatan konten, preview, dan approval.
3. **Distribution** — hand-off konten yang sudah disetujui ke Metricool untuk scheduling.

## Connector Baseline

- AI Connector
- Web/Research Connector
- Link Analyzer
- Metricool Connector

## Publication Status

`Draft` → `Menunggu Approval` → `Approved` → `Terjadwal` → `Terkirim`

Error path:

`Gagal` / `Perlu Retry`

## Prinsip

- Tidak membuat listing produk palsu.
- Preview dan approval wajib sebelum publishing.
- UI harus sederhana dan jelas.
- Konten harus melalui approval sebelum distribution.
